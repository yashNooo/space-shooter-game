# Space Shooter:

A 2D space survival shooter made with Python and Pygame.

Meteor storms are destroying Earth. Help the last dinosaurs escape through space in their spaceship. Avoid meteors, fire lasers, and survive for as long as possible.

## Controls

| Key | Action |
|---|---|
| Arrow Keys | Move the spaceship |
| Space | Start the game and fire lasers |

## Features

- Spaceship movement in 4 directions
- Laser shooting with space
- Random rotating meteors
- Explosion animations
- Three-life health system
- Survival score counter

## Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/yashNooo/space-shooter-game.git
cd space-shooter-game
```

### 2. Create and activate a virtual environment

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Install the required library

```bash
pip install pygame-ce
```

### 4. Run the game

```bash
python3 main.py
```
